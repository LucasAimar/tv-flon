# Logos de TV

La app busca el logo de cada canal **primero acá**, en `logos/<id>.png`, y si no lo
encuentra usa el del campo `logo` de `canales.json`. O sea: cualquier archivo que subas
con el nombre correcto reemplaza al logo que haya, sin tocar el JSON ni recompilar
(el TV lo toma la próxima vez que abre la grilla; puede tardar unos minutos en aparecer).

## Cómo tienen que ser
- **Formato:** PNG ideal (JPG también anda, pero el nombre igual tiene que terminar en `.png`).
- **Fondo:** transparente o blanco. La tarjeta pone el logo sobre un gris muy claro.
- **Tamaño:** entre 300 y 600 px de ancho. Horizontal o cuadrado, da igual: se ajusta solo.
- **Peso:** idealmente menos de 200 KB.
- **Nombre:** exactamente el `id` del canal + `.png`, en minúsculas.
